# tor4yclient

Started as a chest ESP mod, grown into a small utility client. Everything is configured in-game — no ModMenu required — by pressing **\\** (backslash).

## Features

- **ESP**
  - **Block Entities** — chests, barrels, shulker boxes, hoppers, furnaces, spawners, and more. Each type has its own on/off and color.
  - **Mobs** — shows nearby mobs with their name above the box.
  - **Players** — shows nearby players; whoever is under your crosshair is highlighted in red.
  - **Ore** — finds coal, iron, copper, gold, redstone, lapis, diamond, emerald, and ancient debris through walls.
  - Each category has its own render style: boxes only, lines only, or both.
- **Spawner Finder** — lists the coordinates of nearby monster spawners, with an optional mob-type filter.
- **Auto RTP** — periodically sends a configurable command (e.g. `/rtp`) and plots where each teleport landed on a small map.
- **Hotbar hotkey** — cycles the selected hotbar slot within a configurable range.
- **Auto Sprint** — sprints automatically while walking forward.
